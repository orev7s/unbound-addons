Shows an image's file name under it in chat.

## What it does

- :photo: Adds the attachment's file name to the message row of each image.
- :eye: On by default. The name is written in italics after the message text.

## Settings

- **Show the extension** keeps the `.png` or `.jpg` at the end of the name. On by default.
- **Longest name** truncates a longer file name with an ellipsis.
