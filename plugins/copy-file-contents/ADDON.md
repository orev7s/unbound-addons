## :sparkle: What it does

- :file-content: Adds **Copy file contents** to the long-press menu of a message with a text attachment.
- :clipboard: Fetches the file and puts its text on the clipboard, so a `.txt`, `.md`, `.json`, `.csv`, code or log file copies without a download.
- :ban: Skips anything that is not text, and anything bigger than the size limit.

## :gear: Settings

- **Largest file** is the biggest attachment it will copy, in bytes. Files over it are left alone.
