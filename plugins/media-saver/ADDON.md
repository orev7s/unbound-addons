Stops images and videos loading on mobile data.

## What it does

- :cloud: Returns no source for the media a connection should not carry, so the image stays blank until you load it.
- :gear: Wifi always loads. Cellular, a metered link and Low Data Mode follow the choices below.
- :eye: The policy is read on every image render, so switching networks takes effect right away.

## Settings

- **Stop media on mobile data** turns the whole feature on or off. On by default.
- **Also load on metered** loads everything on mobile data, whatever the choices below say.
- **Images**, **GIFs** and **Videos** are skipped on mobile data by default; **Emojis** and **Stickers** still load.
